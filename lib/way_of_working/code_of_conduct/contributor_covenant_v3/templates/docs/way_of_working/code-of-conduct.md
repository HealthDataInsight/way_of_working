# Code of Conduct

## Purpose

We adopt the [Contributor Covenant v3][covenant] to establish clear behavioural expectations, create safe inclusive environments, prevent discrimination/harassment, and reduce conflicts.

{: .important }
Adoption requires more than adding `CODE_OF_CONDUCT.md`. Please read the [Addressing and Repairing Harm][enforcement] section and discuss with your team.

## Scope

Applies to all project spaces and community interactions.

**Promotes:** Respectful communication, collaboration, inclusive language, professional conduct, repairing harm

**Prevents:** Harassment, character attacks, stereotyping/discrimination, sexualization, violating confidentiality, endangerment

## Requirements

1. Contact method for reports (email address)
2. Community Moderators responsible for investigation and enforcement
3. Enforcement ladder (consequences and repair)

{: .note }
Use HDI Code of Conduct email address as contact method.

## Setup

```bash
way_of_working init code_of_conduct --contact-method [CONTACT METHOD]
```

## Usage

Command creates `CODE_OF_CONDUCT.md` in repository root.

**Post-setup:**

1. Review the enforcement ladder with team (edit it if your community has its own established process)
2. Assign Community Moderators
3. Communicate adoption to contributors
4. Link from README and CONTRIBUTING

**Enforcement process:**
Report → Investigate → Apply consequence → Repair → Document

## Enforcement

**Enforcement ladder:**

- **Warning:** Single incident or series of incidents
- **Temporarily limited activities:** Repeated violation after a warning, or a more serious first violation
- **Temporary suspension:** Pattern of repeated violation, or a single serious violation
- **Permanent ban:** Violations other steps have failed to resolve, or too serious to keep the community safe

**Requirements:**

- Consistent enforcement by Community Moderators
- Confidential handling, 5-day response
- Document incidents, annual review

## Examples

**Encouraged:** Respecting community purpose, engaging kindly and honestly, respecting different viewpoints, taking responsibility, constructive feedback, repairing harm

**Restricted:** Harassment, character attacks, stereotyping or discrimination, sexualization, violating confidentiality, endangerment, misleading identity, failing to credit sources
